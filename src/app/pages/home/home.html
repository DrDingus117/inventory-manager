📦 Inventory Manager

Welcome! This application allows users to manage inventory items using an authenticated REST API.

What You Can Do

  • 📋 View inventory items
  • ➕ Add new inventory items
  • ✏️ Edit existing inventory items
  • 🗑️ Delete inventory items

Project Features

  • ✅ Angular application
  • ✅ Tailwind CSS configured
  • ✅ Angular routing
  • ✅ Authenticated REST API
  • ✅ HTTP Client
  • ✅ Full CRUD functionality
